# Metrics & Token Economics

Unified metrics for the **Aegis Guardrails** (`v3.2.0`) governance system — token costs, empirical telemetry, and quality benchmarks.

---

## Measurement Methodology

All token values in this document are empirical, step-based measurements, generated by `aegis_core/metrics.py` (`WORDS_TO_TOKENS_FACTOR = 1.35`).

1. **Standardized Calibration**: We use a `1.35` Word-to-Token ratio calibrated specifically for Gemini, since the `count_tokens` API is the gold standard for our platform.
2. **Model Independence**: By framing savings as "prevented steps" or "prevented rework loops" rather than just raw token counts, our ROIs remain valid across different models (Flash, Pro, Opus).
3. **Dataset Separation**: Analysis draws from two distinct datasets: our governed benchmark sessions (17 deep analytical sessions) and an expanded Phase 11 dataset (66 masked alternative-model sessions running partial governance).

### Review Protocol Output Budgets (6 Modes + 6 Prongs)

> [!NOTE]
> Review Protocols (`aegis_core/taxonomy.py`) are executed via subagent isolation. The parent orchestrator does NOT load the full context of the code being reviewed; instead, it delegates to ephemeral subagents that only load the target files. The values below represent *output budgets* and step limits, not parent context pollution.

| Protocol *(Legacy Alias)* | Dispatches | Cost / ROI |
|:--------------------------|:----------:|:-----------|
| **Patrol** *(Breeze)* | 2 Flash | Fast-tracks known defects; BLOCK auto-escalates to Vanguard |
| **Sweep** *(Gale)* | 3–4 Flash | Prevents ~22 rework steps |
| **Vanguard** *(Trident)* | 5–8 Flash | Prevents architectural regressions (saves ~50-80 steps) |
| **Bulwark** *(Maelstrom)* | 7–12 Flash | Caught 5 critical bugs in dogfooding |
| **Fortress** *(Tempest)* | 8–12 Flash | High assurance; human gate before verdict |
| **Citadel** *(Supercell)* | 10–16 Flash | Apex assurance; adversarial Prosecutor/Defender pairs per prong, zero deferrals |

| Prong *(Legacy Alias)* | Cost | Role |
|:-----------------------|:-----|:-----|
| **Sentry** *(Spores)* | 3–4 scouts | Width survey, problem identification |
| **Trace** *(Mycelium)* | 1–2 Flash | Blast-radius mapping, 2-hop import chain tracing |
| **Probe** *(Roots)* | 1–2 analysts | Root-cause analysis + concrete fix proposals |
| **Gauntlet** *(Thorns)* | Adversarial | NASA IV&V falsification, 2-cycle revision cap |
| **Bastion** *(Bedrock)* | Structural | SHIP/BLOCK gate (read-only, does NOT run tests) |
| **Debrief** *(Mulch)* | 1 Flash | Post-review learning extraction (`governance/debrief_queue.jsonl`) |

**Key cost mechanisms:**

- **Empirical Refutation Gate**: Structural check. Eliminates ~80% false positives (empirically observed); saves ~15–30 steps per avoided phantom bug chase.
- **Incremental Escalation**: Preserves completed prongs across 7 upgrade paths, saving ~4–8 steps per review upgrade.
- **Mechanical Diff Downgrade**: ~85% token reduction by down-tiering exact diff application to Flash.
- **JIT Context Clamping (`aegis_mcp/jit_engine.py`)**: Bounds repo-local `.aegis/rules/` injection to `JIT_DEFAULT_MAX_TOKENS = 2000` (prioritizing `invariant` and `gate` rules via `JIT_GATE_TIER_RATIO = 0.60`).

## Quality Benchmarks

### First-Pass Success Rate (FPSR)

- **Target & Benchmark**: > 80% FPSR, calibrated against Tencent SiriusDeliver 2026 (87.2% FPSR).
- **The Guess-and-Check Tax**: Failures without type/signature verification lead to multi-turn debugging cascades costing **~15–25 steps** per defect.
- **Halt & Diagnose Circuit Breaker**: FPSR < 50% across N ≥ 5 code writes → immediate coding halt + structured diagnosis (`failure_mode`, `root_cause`, `broken_invariant`, `fix_spec`).
- **TDD Red-Phase Exemption**: Intentional test failures in red-green-refactor workflows do not penalize FPSR.

### Accuracy-Driven Savings Over Time

The biggest cost driver isn't token consumption — it's **rework loops**:

```
Agent claims "fixed" → User tests → Same error → Agent re-investigates → Finds real cause → Applies correct fix
```

Each loop costs **~20–25 steps** of wasted context. Compound effect: rework fills the context window with noise, degrading accuracy on subsequent turns.

| Timeframe | Without Governance | With Governance | Savings |
|:----------|:-------------------|:----------------|:--------|
| Per incident | ~22 rework steps | ~3 steps (first-time-right) | ~19 steps |
| Per session (~600 steps) | ~5 incidents × 22 = 110 steps | ~1 incident × 22 = 22 steps | ~88 steps |
| Per month (20 sessions) | ~2,200 wasted steps | ~440 wasted steps | **~1,760 steps** |

> [!TIP]
> The governance rules cost 3,743 tokens/turn to maintain. A single prevented rework loop saves ~22 steps. **The rules pay for themselves within ~13-21 turns.**
