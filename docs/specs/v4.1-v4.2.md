# Spec: v4.1 (team, hooks, skills) and v4.2 (adoption, packs, measurement)

- **Status**: accepted 2026-10-15. On that date the author extended the implementation scope through v4.2.0.
- **Tags**: tags still follow ADR 0005 AD-10 (soak, CI green on the exact SHA, human merge).
- **Prune boxes**: every feature here has a hypothesis/prune box (build sheet §3).
- **Evidence**:
  - git 2.43 ref probe, 2026-10-15:
    - create-only `update-ref <ref> <new> 0{40}` refuses an existing ref;
    - CAS works from another worktree;
    - a stale old value is rejected with the current value;
    - blob-valued refs survive `gc --prune=now`.
  - Host facts are in host-matrix v2.

## v4.1

### 1. Git-native agent team (AD-7, H3)

Roles are declared and members are live.

- **`.aegis/team.json`** (committed, `{"v":1,"roles":{…}}`) declares roles only, e.g. `{"implementer":{"max":3},"reviewer":{"max":2,"must_differ_from":"implementer","cross_vendor":true}}`. There is no member list.
- **Lease**: a ref `refs/aegis/lanes/<lane>` pointing to a blob:
  ```json
  {"v":1,"lane","role","host","session","branch","paths":[globs],"ts","ttl_s"}
  ```
  Refs live in the common dir, so every worktree sees them.
  - **Claim**: `git hash-object -w --stdin`, then `update-ref <ref> <blob> 0{40}` (create-only).
  - **Renew/transfer**: `update-ref <ref> <new> <old>` (CAS).
  - **Release**: `update-ref -d <ref> <old>`.
  - **Expired** (`ts + ttl_s < now`): a lease may be taken over by CAS against its current value.
  - **Conflicts**: a claim whose `paths` overlap a live lease of another lane fails. Overlap is checked with the one matcher, on the glob set's literal prefixes plus a test-match of each glob against the other's literal prefixes. The rule is documented and conservative: when unsure, it reports a conflict.
- **Self-registration**: agents from any host call MCP `aegis_team` (`claim | renew | release | list`) or the CLI `aegis team claim/renew/release/list/gc`.
  - `host` is server-owned (identity table). `session` is the server instance id.
  - No heartbeat thread exists (B2). Membership is the set of unexpired leases, renewed on tool calls.
- **Trailers**: `aegis team trailer` prints `Aegis-Lane: <lane>`, `Aegis-Role: <role>` and `Aegis-Host: <host>` for the active lease of this worktree's branch. `aegis hook install --trailers` adds a `prepare-commit-msg` hook that appends them.
- **Cross-vendor pairing**: `aegis team verify-pairing <range>` reads trailers. It fails when a commit with `Aegis-Role: reviewer` has the same `Aegis-Host` as the implementer commits it reviews (same lane), or when the role's `must_differ_from` is violated.
- **Post-lane gate**: `aegis check --lane <lane> --base <ref>` is a deterministic diff check (CI or local):
  1. **Containment**: `git diff --name-only base...HEAD` ⊆ the lease `paths`, plus `team.json` `shared` paths if declared.
  2. **Test integrity**: in changed test files, a removed `def test_*`, an added `skip`/`xfail`/`pytest.skip(`, or a net decrease in `assert` count fails unless the commit carries `Aegis-Test-Change: <reason>`.
- **GC**: `aegis team gc` deletes expired leases (CAS-guarded).

### 2. Per-host hooks (host Phase 2, AD-8 honest tiers)

- `aegis hook install --host <h>` registers hooks through the host's settings file: Claude `.claude/settings.json` (project) or `~/.claude/settings.json` (user, default); Codex `~/.codex/hooks.json`; Antigravity `~/.gemini/config/hooks.json`; Gemini CLI `settings.json` hooks.
  - The JSON merge is atomic, refuses unparseable input, uses marker keys, and supports uninstall.
- One entrypoint, `aegis hook run <event> --host <h>`, reads the host payload from stdin and normalizes it to `{tool, paths, command}`. It then applies:
  1. **Scan-before-edit**: on edit/write tools it checks whether this session's ledger has a `scan` event covering the paths. If not:
     - Claude: exit 2, telling the agent to call `aegis_scan` first;
     - other hosts: a warning (they fail open).
  2. **Destructive-command guard** (replaces the cut `command_safety.py`): first project host-native deny rules (Claude `permissions.deny` for `git push --force*`, `git reset --hard*`, `rm -rf /*`, `gh pr merge*`; Codex exec-policy where available). Then a ≤ 60-line argv-token matcher as a fallback for hosts without native deny.
- `doctor` reports each host's hook tier: blocking (Claude), fail-open (Codex), none.

### 3. Skills projection

- `aegis init --skills` (or `aegis skills sync`) copies the packaged `skills/*/SKILL.md` into `.agents/skills/` (Codex, Antigravity, Gemini, Cursor, Copilot) and `.claude/skills/` (Claude Code).
  - Names are normalized to `[a-z0-9-]`, and frontmatter keeps `name` and `description`.
  - Copies are managed by a sidecar `.aegis/state/skills.json` (hashes). Re-sync never overwrites a user-edited copy without `--force`.
- `${SLOT.*}` is rendered at sync time with the host's slot profile, or with neutral wording when the target dir is shared by several hosts.

### 4. gemini-cli host row

- Promoted from "later" to a supported row: the binary is installed on the dev machine.
- Registration uses `gemini mcp add -s user aegis`. Instructions come from `.gemini/settings.json` `context.fileName: ["AGENTS.md","GEMINI.md"]`, merged (opt-in).

## v4.2

| # | Feature | Design |
|---|---|---|
| 1 | Day-0 baseline card | `aegis check --baseline [--json]` (and printed at the end of `init`) reports detected languages, AST drivers, rule count by type, the Layer-1 pass rate on tracked files, and the 5 files with the most findings. Budget < 2 s on this repo; files above 2,000 are sampled, and the card says so. |
| 2 | Ratchet baseline | `aegis check --write-baseline` records current findings `{rule, path, fingerprint}` to `.aegis/baseline.json` (committed). `aegis check` then fails only on findings not in the baseline. Fixed findings are dropped automatically (`--prune-baseline`). |
| 3 | Rule packs (unsigned) | `aegis rule export <out.json> [--min-fitness X] [--type …]` writes a bundle `{"v":1,"rules":[{path,text,sha256}],"sha256":<bundle digest>}`; counters are reset (prior α=2, β=1). `aegis rule import <pack>` checks the digests, validates each rule with the one loader, refuses id collisions unless `--rename`, and writes atomically (reusing the shelved rule-import design note). No signing claim. |
| 4 | Benchmark | `aegis benchmark [--json]` measures `aegis_scan` latency (p50/p95 over N runs on this repo), scan payload bytes and approximate tokens, and Layer-1 throughput (files/s) on a built-in fixture corpus. Explicitly **not** an efficacy measure (ADR 0005 §5). |
| 5 | AST partition check | `aegis team partition-check --lane A:glob… --lane B:glob…` builds per-file call/def/import sets with the Python driver (and Rust when present) and reports cross-lane edges plus a `[FROZEN_SIGNATURES]` block for boundary functions. |
| 6 | Experimental host rows | `cursor`, `copilot`, `kiro`, `windsurf` with documented registration paths, `verified: false`. `init --host` warns, and `doctor` labels them experimental. |
| 7 | Worktree-shared ledger (H5) | `ledger.jsonl` moves to `<git-common-dir>/aegis/state/ledger.jsonl`, shared by all worktrees. Rows carry `worktree`. `aegis migrate --apply` merges per-worktree ledgers, deduplicating by `key`. Rules stay per worktree. |
| 8 | Packaging (host Phase 3, experimental) | `aegis package --host claude-code` writes a Claude Code plugin dir (`.claude-plugin/plugin.json` + MCP server + hooks + skills). `aegis package --host gemini-cli` writes a Gemini CLI extension (`gemini-extension.json` + context file). Both are marked experimental; nothing is published. |
| 9 | Stability statement | README states the v4 public contract (generated reference) and that the 4.x line takes only bug fixes, security fixes and evidence-backed changes. The "Let It Cook" freeze ends when the metrics stabilize (AD-10). |
